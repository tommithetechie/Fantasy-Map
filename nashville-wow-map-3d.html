MAKE IT YOURS

  1. Right-drag (or two-finger drag) to spin the camera, scroll to zoom, and use 3D tilt to drop back to a flat map.
  2. Click Export style.json to download this map's style.
  3. Open Maputnik (maputnik.github.io/editor), choose Open → upload the file.
  4. Restyle anything — colors, label fonts, road widths — and export again.
  5. For a true fantasy typeface, self-host glyphs (the Noto fonts here are the only ones the free tile server ships).
  6. POIs come live from the tiles via Overpass API — query real places and re-skin them as inns, quest hubs, dungeons.
